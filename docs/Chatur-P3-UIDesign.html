Screens#

Each of these opens as a tab in the one window, with the conversation still pinned to its right.

Added to Process run, a phase 2 screen (2026-10-08, BRD-159 to BRD-179). Mockup: mockups/process-run.html. A work step (not a check or an owner stop) is handed to the agent that owns the process. Process run gains one region for it, and the conversation panel carries the agent's work; nothing else on the screen changes. End-to-end run needs no new control: running-now already names the agent and its model, and its Stop now also ends the handed agent's session.

RegionControlShows or binds
handed-stepCard + Badge + Alert (warning) + Buttonthe agent working the step, its model and tier, the task it was given (run, step, wording, project), the files written and commands run so far, any refused tool, its final message when it finishes, and Stop, which ends the agent's session and the run
msg-handed-stepconversation messagethe handed session's messages and tool calls, live, under the agent's name with the run and step

States of handed-step: empty — a step that is not handed (a check, an owner stop, verify-phase's own steps) shows no region · loading — the agent is being started: the state reads "starting", the lists are empty and Stop is live · error — the agent's session ends in an error or stalls: the region turns to the warning colour with the reason, and the stall-and-retry rule (BRD-124) applies.

Added to Processes, a phase 2 screen (2026-11-10, BRD-192, BRD-195 to BRD-200, BRD-205, BRD-208, BRD-209). Mockup: mockups/processes.html. Start on build-phase, verify-phase or fix-issues now opens an estimate first. Every estimate table in Chatur has the same columns: line of work, model and tier where steps differ, output tokens low · middle · high, time low · middle · high, and where the runs came from. Start writes the estimate batch; Cancel writes nothing.
