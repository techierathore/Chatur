The kind of work wins over the agent. The Verifier sits in Tier 2, but when it is asked to write code it is given Tier 1.
When a model will not answer
Chatur moves to the next model in that tier's chain, tells you in the conversation which one answered, and carries on. It does not stop to ask.
Move up a tier after failed fixes
A model that has failed to fix the same thing three times is given the tier above it, once, for that one piece of work.

Let Chatur choose the modeloff
A small model inside TechieRag reads the request and chooses the tier, so a one-line question never reaches Claude Opus 5.
Turning it off restores these tiers exactly as they are above — nothing here is lost while it is on.
