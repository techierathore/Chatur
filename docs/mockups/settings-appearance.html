Where themes come from
A theme is a named set of colour values, written in the same shape TrBlazeUI already reads — a background, a card, text, lines, one accent, and the few colours used for good news, a warning and a failure.
Chatur ships four of them. Nothing about a theme is compiled in: a fifth can be added from a file, and it appears above beside the others without a line of code changing.
