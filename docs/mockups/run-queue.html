How the queue behaves
One run at a time.
The next one starts the moment the one above it finishes, is stopped or is removed. Nothing runs in parallel, so two runs never touch the same file at once.
A paused run carries on from the step it stopped on.
MyDiary paused inside step 3. When it resumes it re-reads the checklist and picks step 3 back up — it does not begin again at step 1.
A resumed run continues from the open requirement furthest from verified.
Blocked first, then partial, then untouched — so the hardest thing left is the next thing attempted, not the easiest.
A removed run is never started. Whatever it already did stays where it is — the files it wrote, the requirements it closed and the tokens it spent are all in its run record.
