C Chatur — every screen
Chatur, drawn

Three windows. The start window opens first and has nothing in it but your projects and the ways in. The main window is where work happens — menu bar, files down the left, tabs in the middle, the conversation on the right. The other window holds everything that is not the work: prerequisites, the repository, settings. Nothing here works: it is a drawing, made to be argued with before anything is built. The menus and the pickers do open, so try them.

Phases 2, 3 and 4

These are drawn now and built later. Phase 1 is the whole product at its smallest — sign in, open a project, direct an agent, approve its work, check it in. These twelve screens are the phases after it, drawn at this stage only so their shape is agreed before phase 1 is built around them. Nothing in this group is being built yet.

What to argue with
1The conversation owns half the main window and never closes unless you close the file view. Everything outside the main window has no conversation at all.
2Chatur picks the agent from the project's state and says why. The model alone is the default, and on an empty folder it suggests the Analyst.
3Prerequisites, the repository and every setting live in one other window with a list down its left. If something in there belongs in the main window instead, it should move now.
