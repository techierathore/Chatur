## Phases

Phase 1 is one phase built in four steps, in the order the brief gives, each step ending as a nightly build the owner uses on real work before the next step begins. Step 1 brings up Sign in, Register, Start, Prerequisites and the window itself — menu bar, toolbar, the files down the left, and the build and run controls. Step 2 fills the conversation on the right and adds the providers, routing, agents and appearance tabs of Settings. Step 3 adds the agent itself — what it is doing, the changes waiting for approval, the sessions, and the corrections and measurements tabs. Step 4 adds the file tabs with their editing and the Repository view.

The shell was redrawn twice on the owner's review (2026-09-21 and 2026-09-22) and is now settled: Chatur is one desktop window with a menu bar, the project's files down the left, one content area of tabs, and the conversation pinned to the right. A view opens as a tab; the conversation never goes away unless the owner closes the file view. The agent is chosen beside the Send button and Chatur pre-selects the one that suits the project's state, with the model itself as the default. Settings holds everything that is not the work, in seven tabs that are seven separate pages. BRD-156 and BRD-157 were added at that review, so phase 1 carries two ranges.
